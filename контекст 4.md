# Контекст сессии 4 - OCR распознавание текста

**Дата:** 28 января 2026

## Что сделано в этой сессии

### 1. OCR распознавание текста (Tesseract)

- Установлен и настроен **Tesseract OCR** с поддержкой русского языка
- Создан `backend/app/services/ocr_service.py` с функциями:
  - `ocr_pdf_page()` - распознавание страницы PDF
  - `ocr_pdf_page_with_boxes()` - распознавание с координатами слов
  - `preprocess_image()` - предобработка изображений (контраст, резкость)
- Добавлена модель `PageText` для хранения OCR результатов в БД
- Добавлены API endpoints:
  - `GET /api/cases/{id}/volumes/{id}/ocr-stream` - SSE поток OCR прогресса
  - `GET /api/cases/{id}/volumes/{id}/all-pages-text` - получение всего текста
  - `GET /api/cases/{id}/volumes/{id}/page/{num}/text` - текст одной страницы

### 2. Интерфейс просмотра OCR текста

- Добавлена кнопка "Распознать текст" с прогресс-баром
- Добавлена кнопка "Показать текст" для отображения OCR
- Реализован **split view** - PDF слева, OCR текст справа
- Текст отображается как **лента страниц** (скролл как у PDF)
- Добавлен **тулбар** с:
  - Навигация по страницам (поле ввода номера)
  - Зум (+/-)
  - Скачивание текста (.txt)
  - Печать

### 3. Стилизация

- Фон OCR колонки: `#52555a` (как у PDF viewer)
- Тулбар: 56px высота, серый `#38383b`
- Страницы: белые листы с тенью
- Шрифт: Arial 6.5px, line-height 1.15, justify

### 4. Исправления

- Исправлен `vite.config.ts` - proxy на порт 8000 (был 8083)
- Добавлен статус "ocr_completed" в VolumesPage

## Как запустить OCR

1. Открыть том: `http://localhost:3000/cases/1/volumes/2/view`
2. Нажать "Распознать текст"
3. Дождаться завершения (прогресс показывается)
4. Нажать "Показать текст"
