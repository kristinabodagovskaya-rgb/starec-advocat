## 1. Исправление проблемы прерывания OCR при закрытии браузера

### Проблема
При закрытии вкладки браузера или обновлении страницы процесс распознавания текста (OCR) прерывался. Это приводило к потере денег, так как API (Mistral/Claude) списывало оплату за обработанные страницы, но результаты терялись.

### Причина
OCR работал через Server-Sent Events (SSE) - потоковую передачу данных от сервера к браузеру. При закрытии браузера соединение разрывалось и сервер прекращал обработку.

### Решение
Переработана архитектура OCR:
- Создан фоновый процесс распознавания, который работает независимо от браузера
- OCR запускается в отдельном потоке (Python threading) и продолжает работу даже после закрытия страницы
- Добавлена таблица `ocr_runs` для отслеживания всех запусков OCR
- Добавлена таблица `page_texts` для сохранения распознанного текста каждой страницы

### Новые возможности
- **Возобновление OCR** - если процесс прервался (например, ошибка сети), можно продолжить с последней обработанной страницы, а не начинать сначала
- **История OCR** - видно все запуски распознавания для каждого тома
- **Статус в реальном времени** - на странице отображается прогресс распознавания

## 2. Семантический поиск по документам

### Что реализовано
Добавлена возможность искать информацию по смыслу во всех распознанных документах дела.

### Как работает
1. **Векторизация** - после OCR текст разбивается на фрагменты (chunks) по ~1000 символов с перекрытием
2. **Создание embeddings** - каждый фрагмент преобразуется в числовой вектор через OpenAI API (модель text-embedding-3-small)
3. **Поиск** - при запросе пользователя его текст также преобразуется в вектор и сравнивается со всеми фрагментами по косинусному сходству

### Технические детали
- Изначально планировалось использовать бесплатную локальную модель sentence-transformers, но из-за нехватки оперативной памяти (8GB на Mac) модель не загружалась
- Переключено на OpenAI API - работает мгновенно, стоимость минимальная (~$0.0001 за запрос)

### Интерфейс
- На странице дела добавлено поле "Поиск по делу"
- Результаты показывают: том, страницу, фрагмент текста, релевантность в %
- При клике на результат открывается PDF на нужной странице

## 4. Переход на нужную страницу из поиска

### Проблема
При клике на результат поиска открывался том, но не переходил на конкретную страницу.

### Решение
- Добавлено чтение параметра `page` из URL
- PDF viewer теперь открывается сразу на нужной странице
- Панель OCR текста также переключается на соответствующую страницу
