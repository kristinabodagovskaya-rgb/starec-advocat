## Хронология сессии

### 1. Расчёт стоимости API
- Тест 30 страниц = $0.14
- Полный PDF 322 страницы = ~$1.50

### 2. Проблема с git push
- Причина: токен GitHub CLI просрочен
- Решение: `gh auth login` → авторизация через браузер
- Команда: `gh auth setup-git` для настройки git credentials

### 3. Написан отчёт по алгоритмам
Протестировано 10+ алгоритмов:

| № | Алгоритм | Документов | Статус |
|---|----------|------------|--------|
| 1 | Regex + структурный анализ | 6-10 | Мало |
| 2 | Claude Haiku (текст) | 168 | Много |
| 3 | Claude Haiku (текст, строгий) | 107 | Много |
| 4 | GPT-4o-mini (текст) | 45 | Близко |
| 5 | GPT-4o (текст) | 60 | Близко |
| 6 | Claude Vision Haiku (100%) | 50/50 | Всё подряд |
| 7 | Claude Vision Haiku (строгий) | 0 | JSON ошибки |
| 8 | Claude Vision Haiku (30%) | 183 | Много |
| 9 | Claude Vision Haiku (50%) | 107 | Много |
| 10 | **Claude Vision Sonnet (50%)** | **51** | **Точно!** |

### 4. Объяснение алгоритма
Алгоритм работает так:
1. PDF → страница N
2. Обрезка верхних 50%
3. Конвертация в Base64
4. Отправка в Claude Vision Sonnet
5. Ответ JSON: {is_start, title, date, type}
6. Группировка в список документов

### 5. Тестирование страниц 175-332
- Изменён диапазон в коде для тестирования
- Найдена ошибка: "Рапорт" выделен на стр. 193 (это ОПИСЬ!)

### 6. Анализ ошибки (стр. 193)
**Проблема:** Claude увидел слово "рапорт" в ТАБЛИЦЕ ОПИСИ и решил что это документ

**Причина:** Слово "Копия рапорта об..." в ячейке таблицы было воспринято как заголовок документа

### 7. Улучшение промпта с ASCII-шаблонами
Добавлены визуальные шаблоны прямо в текст промпта:

```
=== ШАБЛОН: НАЧАЛО ДОКУМЕНТА (is_start=true) ===

┌────────────────────────────────────────┐
│            ПОСТАНОВЛЕНИЕ               │ ← КРУПНЫЙ заголовок
│    о возбуждении уголовного дела       │
│  г. Москва                 01.11.2011  │ ← ДАТА обязательна
└────────────────────────────────────────┘

=== ШАБЛОН: ОПИСЬ/ТАБЛИЦА (is_start=false) ===

┌────┬─────────────────────────┬────────┐
│ №  │ Наименование документа  │ Листы  │
├────┼─────────────────────────┼────────┤
│ 2  │ Копия рапорта об...     │  6-7   │ ← это НЕ документ!
└────┴─────────────────────────┴────────┘

=== ШАБЛОН: ПРОДОЛЖЕНИЕ (is_start=false) ===

┌────────────────────────────────────────┐
│  ...рассмотрев материалы проверки...   │
│           ПОСТАНОВИЛ:                  │ ← резолюция, НЕ заголовок!
└────────────────────────────────────────┘
```
