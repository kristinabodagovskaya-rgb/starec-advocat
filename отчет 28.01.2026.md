## Хронология работы

### Сессия 1: OCR с Tesseract (утро-день)

#### Начальное состояние:
- В проекте уже была базовая реализация OCR с Tesseract
- Качество распознавания было низким
- Текст не соответствовал PDF по количеству строк

#### Что тестировалось и изменялось:

**1. Попытка улучшить качество Tesseract:**
- Увеличили DPI с 150 до 300
- Добавили предобработку изображений:
  - Конвертация в grayscale
  - Autocontrast
  - Пробовали binarization (Otsu threshold)
  - Пробовали denoising
- **Результат:** качество стало ХУЖЕ, появились артефакты

**2. Откат к простой предобработке:**
- Убрали binarization и denoising
- Оставили только grayscale + autocontrast
- **Результат:** качество вернулось к приемлемому

**3. Эксперименты с PSM режимами Tesseract:**
- Пробовали PSM 4 (assume a single column of text)
- **Проблема:** текст стал отображаться узким столбиком
- Вернули PSM 6 (assume a single uniform block of text)

**4. Проблема: страницы OCR не соответствуют PDF**
- На PDF документы с 30 по 71, на OCR — с 30 по 60
- Часть информации не помещалась на страницу

### Сессия 2: Улучшение отображения текста (вечер)

#### Проблема:
Текст OCR не помещался на страницу — шрифт слишком большой, строки обрезались.

#### Что тестировалось:

**1. Автоподбор размера шрифта (первая версия):**
```javascript
const lines = text.split('\n').length
const contentHeight = 554
const lineHeightRatio = 1.2
let fontSize = contentHeight / (lines * lineHeightRatio)
fontSize = Math.max(5, Math.min(12, fontSize))
```
- **Проблема:** не учитывалась длина строк, текст переносился и не помещался

**2. Добавили учёт длины строк:**
```javascript
const avgLineLength = text.length / Math.max(lines, 1)
if (avgLineLength > 80) fontSize *= 0.85
if (avgLineLength > 100) fontSize *= 0.8
```
- **Результат:** стало лучше, но всё ещё не идеально

**3. Эксперименты со шрифтом:**
- Пробовали моноширинный Courier New
- **Отклонено пользователем** — "шрифт такой не надо"
- Вернули Arial

**4. Эксперименты с letter-spacing:**
- Добавили `letterSpacing: '0.3px'`
- **Отклонено** — не то что нужно

**5. Финальные настройки (утверждены пользователем):**
```javascript
// Автоподбор размера шрифта
const lines = (page.text || '').split('\n').length
const contentHeight = 554
const lineHeightRatio = 1.15
let fontSize = contentHeight / (lines * lineHeightRatio)
fontSize = Math.max(5, Math.min(9, fontSize))  // макс 9px

// Стили
fontFamily: 'Arial, sans-serif'
lineHeight: 1.15
textAlign: 'justify'
```

#### Итерации подбора максимального шрифта:
1. Было: 12px → не помещалось
2. Уменьшили до 10px → почти поместилось (не хватало 2 строки)
3. Уменьшили до 9px → **ОК, утверждено**

### Сессия 4: Улучшение промпта Claude OCR

#### Проблема:
На скриншоте видно, что Claude не распознаёт рукописный текст в таблицах.

#### Первый промпт (базовый):
```
Распознай весь текст на этом изображении документа.

ВАЖНО:
1. Сохрани оригинальное форматирование
2. Сохрани переносы строк
3. Для таблиц используй пробелы
4. Не добавляй пояснений
5. Включи номера страниц, даты, подписи
```

#### Улучшенный промпт (версия 2):
Добавили инструкции про:
- Рукописный текст
- Таблицы с табуляцией
- Изображения с описанием

#### Пользователь предложил свой промпт (~500 токенов):
Очень детальный, но слишком длинный. Включал:
- Markdown-таблицы
- Формат `(возм. X)` для сомнений
- `[ВЛОЖЕННЫЙ ТЕКСТ]` для сканов внутри сканов
- Маркеры страниц `— СТРАНИЦА 1 —`

#### Мой анализ промпта пользователя:
**Плюсы:**
- Формат `Ярутов (возм. Яругов)` — гениально
- `[ВЛОЖЕННЫЙ ТЕКСТ]` — полезно
- "Никогда не выдумывай" — важное правило

**Минусы:**
- Слишком длинный (+$0.02-0.03 на 10 страниц)
- Markdown-таблицы сломают наш UI
- `— СТРАНИЦА 1 —` дублирует нашу постраничную обработку

#### Финальный промпт (утверждён):
```
Ты — OCR-ассистент. Распознай весь текст с изображения документа.

ПРАВИЛА:

1. СТРУКТУРА: сохраняй оригинальное расположение текста, переносы строк, отступы. Не переупорядочивай.

2. ТАБЛИЦЫ: используй табуляцию для колонок. Сохраняй структуру строк и столбцов.

3. РУКОПИСНЫЙ ТЕКСТ: распознавай максимально точно. При сомнениях — указывай варианты: Ярутов (возм. Яругов). Если полностью неразборчиво — [неразборчиво].

4. ИЗОБРАЖЕНИЯ: на месте фото, схем, печатей пиши [ИЗОБРАЖЕНИЕ: описание]. Например: [ИЗОБРАЖЕНИЕ: подпись "А.И. Петров", дата 12.04.2025]. Если внутри изображения есть текст (скан документа внутри документа) — [ВЛОЖЕННЫЙ ТЕКСТ: содержимое].

5. МЕТАДАННЫЕ: включай номера страниц, даты, штампы, колонтитулы — всё что видишь.

6. ТОЧНОСТЬ: никогда не выдумывай текст. Не исправляй опечатки без пометки. Не упрощай и не перефразируй.

Выведи ТОЛЬКО распознанный текст без комментариев:
```

#### Настройки DPI для Claude:
- Было: 150 DPI (экономия токенов)
- Стало: 200 DPI (лучше для рукописи)

|----------|---------|---------|
